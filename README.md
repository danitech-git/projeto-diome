PORTUGUÊS

Classificador de nível de Herói/Heroina

O projeto foi desenvolvido em JavaScript para classificar o nível do(a) herói/heroina. 
Foram utilizados: Variáveis, operadores aritméticos e lógicos, laços de repetição e estruturas de decisões. 

Tecnologias: JavaScript e Node.js

Para executa: 

1° Instale as dependências: 
npm install

2° Execute o projeto:
node index.js


INGLÊS 


Hero/Heroine Level Classifier

This project was developed in JavaScript to classify the level of a hero/heroine. The following concepts were used: variables, arithmetic and logical operators, loops, and conditional structures.

Technologies: JavaScript and Node.js

How to run:

1. Install the dependencies:
npm install

2. Run the project:
node index.js
